# Data

Place only data that may be legally and scientifically stored in this repository.

For every admitted source, record:
- source name and version/date;
- acquisition URL or official source;
- original filename;
- SHA-256;
- license/redistribution status;
- whether the file is raw, transformed, or derived;
- transformation script used.

Do not upload third-party data whose redistribution terms are unclear.
Do not replace missing observations with imputed values unless the study specification explicitly says so.
