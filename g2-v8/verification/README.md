# Verification scope — G2 V8

This folder records the publication-facing verification scope for the G2 V8 paper.

The exact-construction result is supported by analytical arguments plus separate exact-arithmetic checks. The finite verification includes 65,780 canonical states and 789,360 ordered candidate-rival support comparisons for the 68-task construction.

The real-data witness verification checks agreement on disclosed values, declared score domains, mean-enclosure bounds, valid rank values, exact-tie handling, and file digests. The recorded verification scope contains 14,560 candidate support comparisons and 364 comparisons against the archived completion.

These checks are implementation cross-checks, not blind external replication.

No file in this public folder should be interpreted as establishing:
- population-frequency estimates from the 80 overlapping traces;
- physical realizability of every logical completion by retraining;
- universal inefficiency of stronger certificates; or
- semantic determination for the 33 inconclusive traces.
